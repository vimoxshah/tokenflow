Receipts

What did this branch cost?

Every turn is attributed to the branch checked out when it ran. Branches join to merged pull requests by name. The result is a number your team can argue with.

1

A PR owns the turns up to its merge, including the work done before it was opened. That work is how the PR came to exist.

2

Turns after the merge sit beside the receipt, never inside it. They are follow-up on a checkout that kept the old branch name.

3

Long-lived branches are flagged. A receipt for main is a receipt for a period, not for one change.

Rule two came from a mistake. The first draft of this page said a 102-line fix cost $2,499. It cost $16. The other $2,483 ran on the same branch over the six days after it merged, and no console showed the difference. The receipt does now.

Guard

A brake that works while the session is still running.

A Claude Code hook reads the live transcript, prices it with the same table, and warns or blocks against caps you declared. Nothing is invented: with no caps set it only informs.

# declare what you want guarded
tokenflow guard --set warnCostUsd=25,maxCostUsd=200
tokenflow guard --set warnContextTokens=200000

# then, mid-session, the hook says:
TokenFlow guard: session spend $61.48 passed the
warning level of $25.00; the prompt now carries
492K tokens (warning level 200K).
Most of each turn now pays to re-send earlier
context. Compact, or start a fresh session with a
short brief, and the per-turn cost drops.

Runs once per prompt and before each subagent is spawned, the two moments a session's cost curve bends. A cap that is reached blocks the next tool call with the reason on screen.

Privacy by construction, not by policy.

The receipts need your transcripts and your repository on the same disk. That is exactly why nothing leaves it.

  • No telemetry, no account, no upload by default. The dashboard binds to 127.0.0.1 only. Every network path there is goes to an address you chose: a folder you sync, a team server you run, your own git remote.
  • Adapters read counts and discard content. The schema has nowhere to put a prompt, a diff or a file.
  • Zero runtime dependencies. A tool that reads your session logs is the wrong place for four hundred transitive packages.
  • Multi-machine sync is a folder you already own. iCloud, Dropbox, Syncthing, a git repo. Daily totals only, off by default.
  • Team names are opt-in per person. A developer appears by name only if they set it themselves.
  • The GitHub App is yours, not ours. Your App, your server, our code. A receipt is read from your repository, posted back to it, and dropped. There is no hosted TokenFlow service to hold anything.
  • Even this page loads no third-party fonts. The faces are served from the same place as the page.

Fair questions.

Is my data sent anywhere?

Not unless you send it. There is no telemetry and no hosted service. Adapters read token counts and metadata and discard prompt text, source code and file contents, and everything lives in ~/.tokenflow, which you can back up or delete. The paths that can leave the machine are all opt-in and all point at an address you chose: a folder you already sync, a team server you run, your own git remote for receipt notes, and a policy pull from that same team server. The MCP server is local stdio with no socket at all.

How is a receipt bounded?

By branch and by merge. A pull request owns the turns on its branch up to the merge, including work done before it was opened. Turns after the merge are reported beside it. Sessions on a detached HEAD are reported as unattributed, never guessed.

Can I trust the cost estimates?

Every built-in rate records its source URL and fetch date. Service tiers are applied as multipliers per request. Models without a published rate show blank with a reason, and every total states how many turns it priced.

Does the guard need anything installed on a server?

No. It is a Claude Code hook that runs on your machine, reads the live transcript incrementally, and prints its verdict. With no thresholds declared it never blocks.

Why does macOS warn on first launch?

The app is unsigned because there is no Apple Developer account behind this free project. Right-click the app, choose Open, then Open again. The gate appears once.
