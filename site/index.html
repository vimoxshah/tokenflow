The questions billing pages can't answer

Vendor consoles show one vendor, one account, at their granularity. TokenFlow reads every tool's local logs on your machine and answers across all of them, at request granularity, with the raw records still on disk so you can check the arithmetic.

What am I actually spending?

Tokens by day, provider, model and interface — plus estimated cost from a versioned price table with its sources printed, and measured cost when a gateway records it.

Where did the tokens go?

Four mutually exclusive buckets that sum to the total: fresh input, cache read, cache write, output. Streaming re-reports collapsed to run-maxima, never summed — the difference is up to 45× on real data.

Is my usage trending up?

Daily series, moving averages, period comparison, forecasts with stated confidence, anomaly alerts — and correlations with git activity labelled as correlations, never as productivity.

Live, in the menu bar

A native macOS app (no Electron) shows today's spend at a glance, per-provider rolling windows, 5-hour session-block countdowns, capacity meters against limits you declare, and exhaustion ETAs.

Three commands

No configuration, no keys, no npm install — there is nothing to install. Node 22.5+ is the only requirement.

# detect what you already have, ingest, open the dashboard
git clone https://github.com/vimoxshah/tokenflow.git && cd tokenflow
npm run setup        # finds ~/.claude*, ~/.codex, ~/.cursor, …
npm start            # refresh → offline file → dashboard at :7799

Just looking? npm run demo generates clearly-labelled synthetic data so you can explore before pointing it at anything real.

Local by construction, not by policy

There is no HTTP client in this codebase at all. The server binds to 127.0.0.1. Adapters read token counts and metadata and discard prompt text, source code, and file content. Everything lives in ~/.tokenflow/, which you can back up or delete. Verify it yourself: grep -rn "fetch\|https\?://" src/.

Installing the macOS app

  1. Download the latest TokenFlow-*.dmg from Releases.
  2. Open the DMG and drag TokenFlow.app into Applications.
  3. Launch from Launchpad. First launch only: right-click → Open → Open (the build is unsigned).
  4. The menu bar item appears. Click it for the full panel; use Start watcher there to keep data current every two minutes.

Prefer terminal-only? The clone-and-run path above gives you everything including the same menu bar app (node bin/tokenflow.js menubar --app).
